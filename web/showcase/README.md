# 屿 YUNI 官网优化版

日程安排优先，睡前小岛和聊天作为可选陪伴。首屏提供正式应用入口，页面内可使用真实日程规则进行演示试排；演示不会读取或写入账号，也不调用 AI。

入口链接暂时沿用当前 Render 应用。未来确认域名或转发方案后，统一替换 `index.html` 中的应用链接即可。

所有资源均在本目录，不依赖外部字体或 CDN。首屏使用 WebP 静态形象；仅点击 NiNi 打招呼按钮后加载 Three.js 与约 2.6 MB 的模型。动作离开视口或切到后台时暂停，播放一次后停止。支持减少动态效果的系统设置和手动暂停。

`planner-core.js` 复用当前 YUNI 应用的日程规则。`nini-player.js`、模型及 Three.js 来自已有官网优化资源；第三方声明保留在 `vendor/three`。

可作为静态网站部署到腾讯云或 Render Static Site。当前目录为独立版本，不覆盖原官网部署包。
